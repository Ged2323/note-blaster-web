# Note Blaster — web

Landing page for the Note Blaster iOS app, served via GitHub Pages.

## Adding media

- Screenshots: drop image files into `assets/screenshots/`, then add an `<img>` tag inside the `#screenshots` grid in `index.html`.
- Video: drop a file into `assets/video/`, then add a `<video>` tag inside the `#videos` grid in `index.html`.

## App Store link

`index.html` has a placeholder `#` on the "Download on the App Store" button (`id="app-store-link"`) — replace with the real listing URL.
